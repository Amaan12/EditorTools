# Changelog

All notable changes to this package will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-20

### Added
- **AssetHub**: Integrated scene and asset management window.
- **CompilationFeedback**: Visual and audio cues for Unity compilation status.
- **EnumGenerator**: Strong-typed enum generator for `SceneId` (label-based), `Tag`, and `LayerMaskId`.
- **FolderSetup**: Project setup tools for directories, packages, and scene hierarchies.
- **GameObject**: Quick GameObject creation from scripts and hierarchy section headers.
- **HierarchyTraversal**: Keyboard shortcut (`Alt+Up`/`Alt+Down`) hierarchy traversal and reordering.
- **Navigation**: Docked window tab cycling with `Ctrl+Tab` / `Ctrl+Shift+Tab`.
- **Scene**: Play from Scene 0 toolbar button and Additive Scene Loader collections.
- **Text**: Context menu option to create Markdown (`.md`) files in the Project window.
- **Samples~**: Samples for Additive Scene Loader, Hierarchy Traversal, and Compile Monkey testing.
