# Hierarchy Traversal Sample

This sample provides a test scene (`HierarchyTraversal.unity`) configured with nested GameObjects to test keyboard-based hierarchy reordering.

## Usage
1. Open `HierarchyTraversal.unity`.
2. Select any GameObject in the Hierarchy window.
3. Use `Alt + Up Arrow` to move the selected GameObject up among its siblings or into parent levels.
4. Use `Alt + Down Arrow` to move the selected GameObject down among its siblings or out of parents.
