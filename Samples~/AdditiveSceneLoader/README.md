# Additive Scene Loader Sample

This sample contains example scenes and a `SceneCollection` asset to demonstrate additive scene loading in the Unity Editor.

## Usage
1. Select `SampleAdditive.asset`.
2. Notice the list of scenes (`SceneAdditive1`, `SceneAdditive2`).
3. Double-click `SampleAdditive.asset` in the Project window or open via Inspector to automatically load the first scene single and subsequent scenes additively.
